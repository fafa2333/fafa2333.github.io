# fafa2333 的作品集

一个简洁、适配手机与电脑的中文作品集首页。

计划发布地址：https://fafa2333.github.io/

## 修改内容

编辑 `index.html` 即可更新页面中的作品、介绍与样式。网页使用原生 HTML 和 CSS，不需要安装依赖或构建。

## GitHub Pages

仓库名称：`fafa2333.github.io`。

在仓库的 Settings → Pages 中选择 Deploy from a branch，分支设为 `main`，目录设为 `/ (root)`。

`.nojekyll` 用于让 GitHub Pages 直接发布静态文件。
