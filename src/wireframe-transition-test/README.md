# 建筑线稿切换实验 — 错时逐笔 V2

独立路径：`/wireframe-transition-test/`。BIT 使用当前对称 V6，Hive 使用当前 V10；直接读取双建筑线稿页的 surface / lines / manifest，不修改原始模型或现有预览组件。正式 Education、点云实验与双建筑页面源码均不变。

## 复用与实现

- 一套 canvas / PerspectiveCamera / WebGLRenderer，两个预加载模型；只有当前阶段指定的一个 root 可见。28° 固定相机、纸白 token、线色、0.8 CSS px 线宽、抗锯齿、GPU 轮廓候选判断、深度遮挡均来自现有线稿实现。
- 从 manifest 的对象范围与名称/role、原始结构标记、水平性和相对高度，在加载时生成 `cadData` 分类。轮廓候选仍通过原有法线面对测试筛选，不会把所有背面线一起画出。
- 取消主体/细节分阶段门控。BIT 楼层带、窗框、圆端、主体与屋顶交错绘制；Hive 肋条、塔体、屋盖与支撑也在同一个重绘阶段交错进行。外轮廓仅有轻微提前量，不需要等主体完成才开始细节。
- 新增 `paths.js`：按对象、结构分类与水平/非水平边族建立端点邻接；普通二度节点关联相连折线，在交叉点优先关联最平直的延续。连续曲线累计实际长度，闭合环有固定路径起点。重合边共用动画，但源边和几何均保留。BIT 47,680 线段形成 13,844 笔，Hive 224,381 线段形成 15,171 笔；最长连续路径分别包含 298 / 974 个原始线段。
- 每笔保存 `cadArc`（各线段在连续路径中的累计长度区间）、`cadAnchor`（长度加权中心）、`cadSchedule`（固定种子、邻域时序、持续秒数、随机正/反方向）。固定种子 20261010；持续时间 0.19–0.50s。短独立边单独是一笔，连续曲线只有一个沿路径移动的笔尖，不为每个细小曲线边赋予随机时钟。
- `line-material.js` 包装原有材质。Shader 把一笔的进度映射到各线段的实际路径区间，在 LineMaterial 生成粗线四边形之前缩短/延伸端点。起始时序综合弱屏幕方向 28%、高度 12%、邻域 28%、稳定随机 32%；相邻线条相关但不整齐同步。屏幕 X 只影响时序，不进行扫描平面裁切，也不做整体透明度淡入。
- 深度底模始终完整且只写 depth，保持绘制期间的正常遮挡。空白阶段两个 root 都隐藏，render 清空画面，draw calls 为 0。正常阶段与扫描阶段为 2 draw calls。完成时 `uCadMode=0`，直接恢复原始端点与材质，不重建几何。
- 所有线几何和属性仅在加载时创建；逐帧只更新少量 uniforms 和可见 root。两套 shader 预先 compileAsync，避免首次切换时编译暂停。

## 时序与交互

`config.js` 集中管理阶段时长、笔画时长上下限、方向/高度/邻域/随机时序权重、轮廓提前量、固定种子和路径连接阈值。默认：擦除 0.85s → 空白 0.15s → 错时重绘 1.0s，总计 2.0s。开始时间乘以“阶段时长 − 该笔持续时间”，保证所有笔画在阶段结束前完成；端点强制恢复，避免尾部残线或缺线。

点击后停止当前拖动及惯性，禁用按钮；保存两栋建筑各自的当前 yaw，并以冻结姿态捕获屏幕投影 X 范围。整体时序仍偏画面左到右，每一笔擦除/绘制方向独立随机选择正向或反向。相机和模型姿态在转场中不更新。首次出现采用原有 BIT +15° / Hive −20°；再次切回保留该建筑最后的 yaw。结束后以零初速平滑恢复 +3°/s 逆时针旋转，水平拖动、方向键操作重新可用，pitch/roll 始终为 0。

支持 ResizeObserver、离屏/隐藏暂停（暂停可见动画时间）、资源释放和 WebGL context 恢复。减少动态效果偏好下立即切换完整模型，并禁用自动旋转与惯性；仍允许手动水平旋转。页面只有建筑和“切换建筑”按钮。

## 验证

- `tests/wireframe-transition.test.mjs`：双向 2.0s 时序、空白期无模型、重复触发保护、减少动态效果/大步进完成、真实数据分类/路径时长、材质兼容、连续曲线单笔进度、反向重合边、交叉点分笔、闭合环与固定种子复现。
- 同时运行现有线稿几何/旋转测试，检查完整模型构图、对称 BIT、Hive 十二塔保留、水平转动与 reduced motion。
- 浏览器实际完成 BIT→Hive 与 Hive→BIT；本轮各阶段截图/姿态记录保存在 `renders/wireframe-transition-test/staggered-v2/`。空白阶段两个模型隐藏、draw calls 为 0。转场中 yaw、pitch、roll、相机、pivot 固定，只有一个建筑可见或全部隐藏。旧版截图保留在上一层目录，不能当作本轮预览。
- 切换后验证鼠标拖动及自动旋转恢复；390×844 窄屏完成切换，canvas 346×309，按钮下置，无溢出。浏览器未报告 shader / WebGL 错误。
- `pnpm build` 构建独立入口。仅本地实验，不发布，不集成 Education。

本轮仅修改实验页的 `viewer.js`、`line-material.js`、`timeline.js`、`config.js`，新增 `paths.js`，更新相关测试和本说明。原模型、线稿材质/风格、双建筑预览、点云页面与 Education 源码均未修改。
